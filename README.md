## Documentation

The complete configuration, command, integration, versioning, and release documentation is available
at [artisantoolbox.wsssoftware.com.br/packages/maintainer](https://artisantoolbox.wsssoftware.com.br/packages/maintainer/).

## Installation

Install Maintainer as a development dependency:

```bash
composer require --dev artisan-toolbox/maintainer
```

Open the interactive menu:

```bash
vendor/bin/maintainer
```

Maintainer is currently in beta. Commands and public behavior may change while its initial workflows are established.
